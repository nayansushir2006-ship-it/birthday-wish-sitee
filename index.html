💡 Setup & Deployment Instructions:

A. Vercel वर अपलोड करण्याची पद्धत:

  1. हा संपूर्ण फोल्डर तुमच्या GitHub वर अपलोड करा.
  2. Vercel.com वर मोफत लॉगिन करा.
  3. तिथे Add New -> Project करून तुमचे GitHub रिपॉझिटरी सिलेक्ट करा.
  4. Vercel मधील कोणतीही सेटिंग न बदलता थेट Deploy वर क्लिक करा!

B. Cloudinary Unsigned Upload Preset मिळवा:

  1. Cloudinary.com डॅशबोर्डमध्ये वरच्या उजव्या बाजूला Settings (Gear icon) वर जा.
  2. डावीकडे Upload निवडून खाली स्क्रोल करा आणि Add Upload Preset वर क्लिक करा.
  3. Preset चे नाव कॉपी करा. Signing Mode बदलून Unsigned निवडा आणि सेव्ह करा.
  4. तेच नाव डावीकडील Upload Preset (Unsigned) मध्ये भरा.

    Cloud Integration Dashboard

    वेबसाईट होस्टिंग आणि क्लाउड स्टोरेज (Vercel, Firebase & Cloudinary) व्यवस्थापन

    Active Environment

    प्रोजेक्ट सर्व्हरलेस चालू आहे (Vercel, स्थानिक किंवा Google Firestore बफर वापरला जात आहे).

    Vercel Serverless Mode

    १. Cloudinary Config (मोफत फोटो/व्हिडिओ स्टोरेज)

    तुमचे फोटो आणि व्हिडिओ क्लाउडवर सेव्ह करण्यासाठी ही माहिती भरा.

    Vercel वरील थेट अपलोडसाठी Cloudinary चे Unsigned Preset सुरु असणे आवश्यक आहे.

    २. Firebase Firestore Config (डेटाबेस)

    Firebase डेटाबेस जोडण्यासाठी तुमची API की प्रविष्ट करा.

    ३. Change Admin Password (पासवर्ड बदला)

    ॲडमिन पॅनेलचा लॉगिन पासवर्ड बदलण्यासाठी नवीन पासवर्ड प्रविष्ट करा.

    💡 Setup & Deployment Instructions:

    A. Vercel वर अपलोड करण्याची पद्धत:
    1. हा संपूर्ण प्रोजेक्ट तुमच्या GitHub वर अपलोड करा.
    2. Vercel.com वर मोफत लॉगिन करा.
    3. Add New -> Project वरून तुमची GitHub रिपॉझिटरी निवडा.
    4. Vercel कोणतीही सेटिंग न बदलता थेट Deploy वर क्लिक करा.
    B. Cloudinary Unsigned Upload Preset कसा निवडावा:
    1. Cloudinary.com डॅशबोर्डमध्ये उजव्या कोपऱ्यात Settings (Gear icon) वर जा.
    2. डावीकडे Upload टॅबवर क्लिक करून खाली या आणि Add Upload Preset वर क्लिक करा.
    3. Preset चे नाव कॉपी करा. Signing Mode मधून Unsigned निवडा आणि सेव्ह करा.
    4. तेच नाव डावीकडील Upload Preset (Unsigned) मध्ये भरा.
